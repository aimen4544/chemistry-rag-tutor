# 🧪 AI Chemistry RAG Tutor

An AI-powered Chemistry tutor that answers questions from real Chemistry textbooks using RAG (Retrieval Augmented Generation).

## 🔗 Live App
👉 Coming soon!

## 📌 What it does
- Answers Chemistry questions from real textbooks
- Uses RAG technique to find relevant content
- Covers Edexcel IGCSE, Cambridge IGCSE and A-Level Chemistry
- Gives detailed step by step explanations

## 🛠️ Built With
- Python
- Groq API (LLaMA 3.3)
- LangChain
- Streamlit
- PyPDF2

## 📚 Textbooks Used
- Edexcel International GCSE Chemistry
- Cambridge IGCSE Chemistry Coursebook
- Cambridge International AS and A Level Chemistry

## 🤖 How RAG Works
1. Load Chemistry textbooks as PDF
2. Split into 1270 text chunks
3. Find relevant chunks for each question
4. Send relevant chunks to AI model
5. AI answers based on textbook content only
